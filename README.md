## 安装

```bash
npx skills add zel-forprogress/changshu-arno-skill@changshu-arno-perspective -g -y
```

## 使用

激活后说以下关键词即可进入角色：

- 「用阿诺的视角」「阿诺视角」
- 「诺言诺语」
- 「常熟阿诺」「盛亦陶」
- 「那我问你」
- 「生米冲碳」「反向带货」「头尖尖」

退出角色说「退出」「切回正常」「认真回答」即可。
